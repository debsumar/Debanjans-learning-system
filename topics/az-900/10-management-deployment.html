Management interfaces

Different interfaces can manage the same Azure resources. Pick based on exploration, repeatability, team workflow, and desired-state control.

InterfaceInterface styleRepeatable?Best for
Azure portalBrowser GUI with dashboards, forms, views, and wizards.Low by itself; clicks are not a durable deployment definition.Exploration, learning, inspection, and one-off changes.
Cloud ShellBrowser-hosted shell with Bash or PowerShell; pre-authenticated to Azure and backed by a persistent file share.Yes when commands/scripts are saved and versioned.Run CLI or PowerShell from a browser without local setup.
Azure CLIaz commands; cross-platform and Bash-friendly, outputs text or structured data.Yes through scripts and pipelines.Cross-platform automation, shell scripting, and concise command workflows.
Azure PowerShellAz module cmdlets with PowerShell objects and object-pipeline composition.Yes through scripts and pipelines.PowerShell automation, Windows-oriented operations, and object manipulation.

ChooseGUI for discovery. CLI or PowerShell for scripted operations. ARM template for repeatable infrastructure definition. Cloud Shell is the hosted place to run Bash or PowerShell; it is not itself a command language.

GUI versus automation

  • Portal: fast feedback and visual discovery, but manual clicks are harder to reproduce consistently.
  • CLI: compact command syntax and easy shell composition across platforms.
  • PowerShell: cmdlets return objects, enabling filtering and pipeline operations in PowerShell.
  • Script: sequence imperative steps when operation order or conditional logic matters.
  • Template: describe desired resources so deployment can be reviewed, repeated, and converged.

Azure Arc

Azure Arc projects resources outside Azure into Azure management. It can connect on-premises and other-cloud servers, Kubernetes clusters, and data services so they can be governed, inventoried, monitored, and managed with Azure tooling.

  • Use Arc when resources remain outside Azure but need a consistent Azure control and governance experience.
  • Arc extends management and policy reach; it does not mean the workload has been migrated into Azure datacenters.
  • Arc supports hybrid and multicloud operations across servers, Kubernetes, and data services.
ConfuseArc ≠ Migrate. Arc brings external resources into Azure management. Azure Migrate assesses and helps move workloads to Azure.

IaC, ARM, and ARM templates

Diagram: Every management surface funnels through ARM; resource data operations use the resource endpoint directly.

Infrastructure as code (IaC) treats infrastructure definitions as code: desired state is declarative, repeatable, version-controlled, and idempotent. Store definitions in source control, review changes, and deploy consistently across environments.

ApproachMeaningStrengthWatch for
ImperativeTell system which steps or commands to execute and in what sequence.Flexible logic, branching, and operational procedures.Repeated runs can drift or fail if steps are not safely repeatable.
DeclarativeDescribe desired end state; engine determines required operations.Consistent, reviewable, idempotent infrastructure deployment.Complex procedural logic may need another mechanism.

Azure Resource Manager (ARM) is Azure’s deployment and management service. Portal, CLI, PowerShell, templates, and SDKs use ARM for Azure management/control-plane requests; data-plane calls go directly to a resource endpoint. ARM authenticates and authorizes management requests and supports policy, resource-group operations, dependencies, and deployment orchestration.

ARM templates are JSON declarative IaC documents. They support idempotent deployments, orchestration and parallel deployment of independent resources, dependencies, parameters, variables, outputs, and modular composition. Bicep is a concise domain-specific language alternative that compiles to ARM template JSON.

Memory hookARM = control plane. ARM template = JSON desired-state document sent through that control plane.

High-yield discriminators

CLI vs PowerShell
CLI uses az commands and is shell-friendly across platforms; PowerShell uses Az cmdlets and object pipelines.
Cloud Shell vs CLI
Cloud Shell is a browser-hosted, pre-authenticated environment; CLI is a command-line tool that can run there or locally.
ARM vs ARM template
ARM is the management and deployment control plane; an ARM template is a declarative JSON deployment definition.
Portal vs template
Portal is visual and useful for exploration or one-off work; template is repeatable, reviewable, and automation-friendly.
Arc vs Migrate
Arc manages external resources in place; Migrate helps assess and move workloads to Azure.

MCQs

  1. 1. Which command family identifies Azure CLI?
    • A. az
    • B. Get-Az
    • C. ARM JSON
    • D. Bicep
    Answer

    Correct: A — az. Reason: Azure CLI uses the az command family for cross-platform command-line operations.

    • B — Get-Az identifies Azure PowerShell cmdlets.
    • C — ARM JSON is a declarative template format.
    • D — Bicep is an IaC language that compiles to ARM template JSON.
  2. 2. An operator wants object-pipeline filtering in a PowerShell script. Which interface fits?
    • A. Azure PowerShell
    • B. Azure CLI
    • C. Portal wizard
    • D. ARM template
    Answer

    Correct: A — Azure PowerShell. Reason: Az cmdlets return PowerShell objects that compose through the object pipeline.

    • B — CLI is shell-friendly but does not provide PowerShell object-pipeline semantics.
    • C — Portal is visual interaction, not a script pipeline.
    • D — A template describes desired state rather than filtering command output.
  3. 3. Which statement correctly separates Cloud Shell from Azure CLI?
    • A. Cloud Shell is the command language; CLI is the browser host.
    • B. Cloud Shell is a hosted environment; CLI is a tool that can run inside it.
    • C. Cloud Shell is an ARM template; CLI is a resource provider.
    • D. Cloud Shell migrates workloads; CLI governs data classification.
    Answer

    Correct: B — Cloud Shell is a hosted environment; CLI is a tool that can run inside it. Reason: Cloud Shell provides browser-hosted Bash or PowerShell; Azure CLI supplies az commands.

    • A — The roles are reversed and neither description is exact.
    • C — Neither is a template or provider.
    • D — Those are unrelated capabilities.
  4. 4. A team needs repeatable, reviewable desired-state deployment of several resources. Which choice is most suitable?
    • A. Manual portal clicks
    • B. ARM template
    • C. Resource endpoint data call
    • D. Azure Status
    Answer

    Correct: B — ARM template. Reason: ARM templates are declarative JSON IaC definitions that support repeatable and idempotent deployment.

    • A — Manual clicks are harder to reproduce and review consistently.
    • C — A data-plane call operates resource data, not infrastructure definition.
    • D — Azure Status reports platform status.
  5. 5. Which component is Azure’s management and deployment control plane?
    • A. Azure Resource Manager
    • B. ARM template
    • C. Azure Arc
    • D. Azure Migrate
    Answer

    Correct: A — Azure Resource Manager. Reason: ARM handles Azure management/control-plane requests, authorization, policy, and orchestration.

    • B — An ARM template is a JSON desired-state document sent through ARM.
    • C — Arc extends management to external resources.
    • D — Migrate assesses and helps move workloads.
  6. 6. A company keeps servers in its datacenter but wants Azure governance and inventory over them. Which service fits?
    • A. Azure Arc
    • B. Azure Migrate
    • C. ARM template
    • D. Azure CLI
    Answer

    Correct: A — Azure Arc. Reason: Arc brings external servers and other supported resources into Azure management without moving them into Azure datacenters.

    • B — Migrate helps assess and move workloads to Azure.
    • C — A template defines Azure resource state.
    • D — CLI is an interface, not hybrid management projection.
  7. 7. A script must use conditional branching and execute steps in a precise order. Which approach is the natural fit?
    • A. Imperative commands or script
    • B. Declarative ARM template only
    • C. Resource provider
    • D. Portal dashboard
    Answer

    Correct: A — Imperative commands or script. Reason: Imperative automation specifies operations and sequence, supporting branching and procedural logic.

    • B — Declarative templates describe desired state; procedural logic is not their primary model.
    • C — A provider implements resource operations behind ARM.
    • D — A dashboard visualizes resources.
  8. 8. A data-plane request to read objects from storage should be routed where?
    • A. Directly to the resource endpoint
    • B. Through an ARM template
    • C. Through the ARM management plane
    • D. Through Azure Migrate
    Answer

    Correct: A — Directly to the resource endpoint. Reason: ARM handles management/control-plane requests; data-plane calls go directly to the resource endpoint.

    • B — Templates deploy desired infrastructure, not resource data reads.
    • C — The management plane is not the normal data-operation endpoint.
    • D — Migrate is unrelated to storage data access.
  9. 9. Which statement best distinguishes ARM from an ARM template?
    • A. ARM is the control plane; a template is a declarative JSON definition.
    • B. ARM is a CLI command; a template is a browser shell.
    • C. ARM migrates servers; a template classifies data.
    • D. ARM is a resource lock; a template is a role assignment.
    Answer

    Correct: A — ARM is the control plane; a template is a declarative JSON definition. Reason: ARM receives and orchestrates management requests; the template describes desired resources.

    • B — Neither role matches these descriptions.
    • C — Arc/Migrate and Purview address unrelated capabilities.
    • D — Locks and RBAC are governance controls, not ARM/template meanings.
  10. 10. A team must manage a Kubernetes cluster outside Azure without first moving it. Which distinction matters?
    • A. Arc manages in place; Migrate helps move workloads.
    • B. Arc estimates cost; Migrate sets budgets.
    • C. Arc is a template; Migrate is a CLI shell.
    • D. Arc is a data endpoint; Migrate is a resource provider.
    Answer

    Correct: A — Arc manages in place; Migrate helps move workloads. Reason: Arc extends Azure management to external resources, while Migrate supports assessment and migration.

    • B — Cost estimation and budgets are different capabilities.
    • C — Neither service is defined as those interface types.
    • D — Those are not their roles.
