Discrimination drill

Attempt each distinction before opening its answer. Links go to the chapter callout that owns it.

Policy vs RBAC vs locks: which tool enforces configuration, grants actions, or blocks changes?

Policy enforces standards; RBAC grants actions; locks block deletion or changes. Open governance callout.

Monitor vs Advisor vs Service Health: are you observing workloads, getting recommendations, or checking Azure events?

Monitor observes workloads; Advisor recommends; Service Health reports Azure incidents and maintenance. Open monitoring callout.

Blob vs Files: is the data unstructured object data or a managed file share?

Blob stores object data; Files exposes managed file shares over SMB or NFS. Open storage callout.

VPN Gateway vs ExpressRoute: which path uses an encrypted public-internet tunnel and which is private and dedicated?

VPN uses encrypted public internet; ExpressRoute uses private dedicated connectivity. Open networking callout.

Availability set vs availability zone: is resilience within one datacenter or across separate datacenter locations?

Set spreads VMs across fault/update domains; zone uses separate datacenter locations. Open compute callout.

Subscription vs resource group vs management group: which scope bills and grants access, contains resources, or organizes subscriptions?

Subscription is billing and access boundary; group organizes resources; management group organizes subscriptions. Open hierarchy callout.

Public vs private endpoint: is the service reached through a public address or a private VNet IP?

Public endpoint uses public IP path; private endpoint maps service to a VNet private IP. Open endpoint callout.

IaaS vs PaaS vs SaaS: how does increasing abstraction change customer management?

More service means less customer management: infrastructure, platform, then complete application. Open service-type callout.

Entra ID vs Entra Domain Services: is this cloud identity or managed domain compatibility?

Entra ID is cloud identity; Domain Services supplies managed domain join, LDAP, and Kerberos/NTLM. Open identity callout.

Region vs region pair vs availability zone: name the geographic area, linked relationship, and isolated location.

Region is geographic area; pair is linked-region relationship; zone is isolated datacenter group inside a region. Open geography callout.

Cross-chapter scenarios

Choose first, then reveal answer and one-line rationale.

An office needs an encrypted tunnel over the public internet to Azure. Choose VPN Gateway or ExpressRoute and say why.

VPN Gateway. It creates an encrypted tunnel over the public internet; ExpressRoute is private dedicated connectivity.

A regulated workload requires a private dedicated provider connection that does not use the public internet. Which path?

ExpressRoute. It provides private dedicated connectivity through a connectivity provider rather than a public-internet VPN.

A Storage account must be reached using a private IP on a VNet network interface. Choose the endpoint.

Private endpoint. It places a private IP on a VNet NIC and connects privately through Private Link.

Three VMs need protection from planned maintenance and localized hardware failure within one datacenter. Choose the placement feature.

Availability set. It spreads VMs across update and fault domains inside a datacenter; zones use separate locations.

A database must remain available when one availability zone fails while staying in one region. Which redundancy idea fits?

Zone-redundant deployment. It spreads copies across zones in one region; a region pair is a linked-region relationship.

A legacy application expects an SMB shared folder mounted by several clients. Choose Blob Storage or Azure Files.

Azure Files. It provides managed SMB or NFS file shares; Blob Storage is for unstructured objects.

A team needs a rule that disallows resources in an unapproved region. Choose Azure Policy, RBAC, or a lock.

Azure Policy. Policy evaluates or enforces resource configuration; RBAC grants actions and locks protect against changes or deletion.

An authorized operator must be prevented from deleting a resource. Choose Azure Policy, RBAC, or a lock.

Resource lock. A lock protects a resource from blocked operations regardless of which authorized identity attempts them.

A team wants a recommendation to right-size an underused VM, not a spend threshold alert. Choose Advisor or Cost Management budgets.

Azure Advisor. Advisor suggests improvement actions; budgets and alerts track spend thresholds.

A legacy app needs LDAP, Kerberos, NTLM, and domain join without deploying domain controllers. Choose Entra ID or Entra Domain Services.

Microsoft Entra Domain Services. It supplies managed domain compatibility; Entra ID provides cloud identity and modern authentication.

A team wants a finished customer relationship application and does not want to deploy code. Choose IaaS, PaaS, or SaaS.

SaaS. SaaS provides finished software to configure and use; IaaS and PaaS leave more of the workload under customer control.

A queue message should trigger short stateless code without VM patching. Choose a VM, container, or function.

Function. Functions are event-driven code units with provider-managed infrastructure; containers package apps and VMs expose guest OS control.

Weight-aware plan

Every chapter currently gets 10 questions regardless of its domain: Domain 1 is 25–30%, Domain 2 is 35–40%, and Domain 3 is 30–35%. Equal chapter counts therefore under-serve higher-weight domains. Review in proportional order, then refine with misses and due items.
