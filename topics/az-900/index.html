AZ-900 Notes

Dense, standalone revision notes for every official Azure Fundamentals objective. Open any file directly from file://.

Each chapter now ends with a diagram and 10 MCQs with answers.

Official objectives

Domain 1 · Describe cloud concepts · 25–30%

01 · Describe cloud computing

Core cloud definition, responsibility, models, pricing, serverless.

02 · Describe the benefits of using cloud services

Reliability, predictability, security, governance, manageability benefits.

03 · Describe cloud service types

IaaS, PaaS, SaaS, shared responsibility, and use cases.

Domain 2 · Describe Azure architecture and services · 35–40%

04 · Describe the core architectural components of Azure

Regions, resource hierarchy, subscriptions, and availability.

05 · Describe Azure compute and networking services

Compute choices, containers, functions, networks, connectivity.

06 · Describe Azure storage services

Storage accounts, blobs, files, queues, tables, redundancy.

07 · Describe Azure identity, access, and security

Entra ID, access control, security posture, defense layers.

Domain 3 · Describe Azure management and governance · 30–35%

08 · Describe cost management in Azure

Factors, calculators, budgets, tagging, and cost analysis.

09 · Describe features and tools in Azure for governance and compliance

Microsoft Purview, Azure Policy, resource locks, and how they differ from RBAC.

10 · Describe features and tools for managing and deploying Azure resources

Portal, CLI, PowerShell, ARM, IaC, and Cloud Shell.

11 · Describe monitoring tools in Azure

Monitor, Advisor, Service Health, alerts, logs, and metrics.
