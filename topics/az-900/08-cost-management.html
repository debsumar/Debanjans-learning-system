What affects Azure cost

Azure bill depends on what is deployed, where it runs, how long it runs, and which commercial offer applies.

  • Resource type and tier: VM size, storage redundancy, database tier, transaction volume, and enabled features change unit price.
  • Consumption versus reservation: pay-as-you-go follows actual use; a reservation or other commitment can lower effective price when workload is predictable.
  • Maintenance and idle resources: running VMs, unattached disks, old snapshots, public IPs, and test environments continue costing money unless stopped, resized, or removed.
  • Geography and region pricing: same service and tier can have different prices by region; data residency and paired-region design also affect choices.
  • Network egress and zone traffic: data leaving Azure or crossing zones can incur charges; ingress is not automatically symmetric with egress.
  • Subscription type and offers: agreement, credits, free services, support plan, and eligibility alter effective cost and limits.
  • Azure Marketplace: third-party offers can add publisher charges, often alongside Azure infrastructure charges; check billing source and terms.
Exam clueCost question usually needs several dimensions: resource SKU + usage duration + region + data movement + purchasing offer.

Cost levers and reductions

Tags for cost allocation

A tag is metadata expressed as a name/value pair, such as department=finance, environment=test, or owner=team-a. Tags label resources for organization, filtering, automation, and cross-cutting reporting.

  • Use tags to allocate or report cost by department, environment, owner, product, or project.
  • Tags support reporting across resource groups; one report can group resources by a shared tag value even when resources sit in different groups.
  • Tags are not inherited by default by child resources. Enforce or propagate standards with Azure Policy.
  • Separately, Microsoft Cost Management tag inheritance can copy subscription or resource-group tags to cost data only; it does not save tags on resources or expose them to other services. Cost allocation can move or split shared costs for reporting without changing the invoice.
  • Tags do not change permissions, create a billing boundary, or replace a resource group.
ConfuseTag vs resource group: tag = flexible metadata for label/reporting across scopes; resource group = lifecycle container whose resources are managed together.
ConfuseAdvisor cost recommendations suggest improvement actions. Cost Management budgets set spend thresholds and alerts. Recommendation is not a budget.
Memory hookCalculator predicts. TCO compares. Cost Management observes. Tags explain who or what owns spend.

MCQs

  1. 1. Which tool estimates the price of a planned Azure design before deployment?
    • A. Microsoft Cost Management
    • B. Pricing Calculator
    • C. Azure Advisor
    • D. Tags
    Answer

    Correct: B — Pricing Calculator. Reason: It projects Azure cost from selected services, regions, tiers, and usage assumptions before deployment.

    • A — Cost Management analyses actual spend after usage.
    • C — Advisor gives recommendations, not initial price estimates.
    • D — Tags label resources and cost data.
  2. 2. A company wants to compare its datacenter operating costs with a possible Azure migration. Which tool fits?
    • A. TCO Calculator
    • B. Pricing Calculator
    • C. Budget
    • D. Azure Advisor
    Answer

    Correct: A — TCO Calculator. Reason: TCO Calculator compares on-premises total cost with an Azure scenario.

    • B — Pricing Calculator estimates an Azure design, not on-premises comparison.
    • C — A budget sets a spend threshold for a scope and period.
    • D — Advisor recommends improvements for existing resources.
  3. 3. Which capability analyses actual Azure spending and supports budgets and alerts?
    • A. TCO Calculator
    • B. Microsoft Cost Management
    • C. Resource group
    • D. Pricing Calculator
    Answer

    Correct: B — Microsoft Cost Management. Reason: Cost Management provides actual cost analysis, budgets, alerts, exports, and recommendations.

    • A — TCO Calculator compares on-premises and Azure totals.
    • C — Resource groups organize resources for lifecycle management.
    • D — Pricing Calculator is a pre-deployment estimate.
  4. 4. A finance team needs one report grouping resources in many resource groups by department. What should it standardize?
    • A. Resource groups
    • B. Tags
    • C. Reservations
    • D. Locks
    Answer

    Correct: B — Tags. Reason: Shared name/value metadata supports cross-cutting reporting such as department or owner.

    • A — Resource groups are lifecycle containers, not flexible cross-group labels.
    • C — Reservations change purchase economics for eligible capacity.
    • D — Locks protect resources from changes or deletion.
  5. 5. A team wants a notification when forecast spend reaches its configured threshold, without automatically stopping resources. What should it configure?
    • A. Budget and alert
    • B. TCO Calculator
    • C. Azure Advisor
    • D. Resource group
    Answer

    Correct: A — Budget and alert. Reason: Budgets define thresholds and alerts notify when actual or forecast spend reaches them; they do not stop resources.

    • B — TCO Calculator compares total-cost scenarios.
    • C — Advisor suggests optimization actions.
    • D — Resource groups organize lifecycle, not spending thresholds.
  6. 6. Azure Advisor flags an underused virtual machine. What kind of output is this?
    • A. A cost recommendation
    • B. A billing boundary
    • C. A pre-deployment estimate
    • D. A tag inheritance rule
    Answer

    Correct: A — A cost recommendation. Reason: Advisor identifies possible savings actions such as right-sizing underused resources.

    • B — A billing boundary is not what Advisor creates.
    • C — A pre-deployment estimate comes from Pricing Calculator.
    • D — Tag inheritance is separate metadata or cost-data behavior.
  7. 7. Which statement best separates a tag from a resource group?
    • A. A tag controls resource permissions; a group controls billing.
    • B. A tag labels metadata across scopes; a group manages resource lifecycle together.
    • C. A tag is a pre-deployment calculator; a group is an alert.
    • D. A tag prevents deletion; a group recommends savings.
    Answer

    Correct: B — A tag labels metadata across scopes; a group manages resource lifecycle together. Reason: Tags support organization/reporting; resource groups are lifecycle containers.

    • A — Tags do not grant permissions, and groups are not billing controls.
    • C — Neither describes those tools.
    • D — Locks prevent deletion, and Advisor recommends savings.
  8. 8. Which sequence is correct for a new workload’s cost review?
    • A. Cost Management → TCO Calculator → deploy
    • B. Pricing Calculator/TCO Calculator → deploy → Cost Management
    • C. Tags → Advisor → TCO Calculator
    • D. Budget → Pricing Calculator → resource group
    Answer

    Correct: B — Pricing Calculator/TCO Calculator → deploy → Cost Management. Reason: Estimate or compare before deployment, then analyse actual spend after deployment.

    • A — Cost Management needs actual usage, so it does not lead this sequence.
    • C — Tags and Advisor do not replace pre-deployment estimation.
    • D — This is not the cost-lifecycle order.
  9. 9. A budget is already alerting, but the team wants a recommendation to resize idle resources. Which service adds that recommendation?
    • A. Azure Advisor
    • B. TCO Calculator
    • C. Tags
    • D. Resource group
    Answer

    Correct: A — Azure Advisor. Reason: Advisor suggests savings actions; a budget only tracks spend against a threshold.

    • B — TCO Calculator compares datacenter and Azure totals.
    • C — Tags add reporting metadata.
    • D — Resource groups organize resources by lifecycle.
  10. 10. Which claim about tags is accurate?
    • A. Tags automatically inherit to every child resource.
    • B. Tags change the invoice amount directly.
    • C. Tags are name/value metadata used for organization and reporting.
    • D. Tags replace Azure Policy for enforcing standards.
    Answer

    Correct: C — Tags are name/value metadata used for organization and reporting. Reason: Tags explain ownership or classification and can support cost allocation; they do not inherently enforce or alter billing.

    • A — Tags are not inherited by default.
    • B — Reporting allocation does not change the invoice itself.
    • D — Azure Policy can enforce or propagate tag standards.
